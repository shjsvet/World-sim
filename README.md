# WorldSim

Симулятор эволюции мира: процедурная генерация карты, геополитика фракций,
летопись событий и контроль версий снимков мира — как Git для истории мира.

> **Статус:** 🟡 ранний каркас. Код ещё не реализован: созданы пакет и документация.
> План работ и статусы — в [backlog.md](backlog.md), промпты задач — в
> [docs/PROMPTS.md](docs/PROMPTS.md), требования — в [docs/TASK.md](docs/TASK.md).

## Требования

- Python 3.11 или новее (проект разрабатывается на 3.12).
- Windows, Linux или macOS.

## Установка

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -e ".[dev]"
```

Для ИИ-модуля (этап 3): `pip install -e ".[ai]"`, затем скопируйте `.env.example` в `.env`
и заполните ключи провайдера. Файл `.env` в репозиторий не попадает — он закрыт `.gitignore`.

## Быстрый старт

```bash
python -c "import worldsim; print(worldsim.__version__)"
```

## Структура проекта

```text
src/worldsim/
├── core/       # доменные модели: деревья, карта, события, снимок мира, летопись
├── generator/  # процедурная генерация стартового мира и фракций
├── engine/     # правила симуляции и шаг времени
├── vcs/        # коммиты, ветвление, diff снимков мира
├── ai/         # ИИ-хроника и генерация конфигураций мира
└── ui/         # Streamlit-интерфейс
tests/          # модульные и интеграционные тесты
docs/           # ТЗ, реестр промптов, архитектурные решения
```

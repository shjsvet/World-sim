# ADR 0002: frozen pydantic

- **Статус:** принято
- **Дата:** 2026-11-23
- **Связанные задачи:** T05–T10

## Контекст

Снимки мира используются одновременно движком, летописью, репозиторием
версий и интерфейсом. Если модель можно изменить на месте, старые снимки
перестают быть достоверными, а diff и checkout теряют смысл. При этом
нужна строгая валидация диапазонов и ссылок.

## Решение

Все доменные модели — pydantic `BaseModel` с `ConfigDict(frozen=True)`.
Изменения выполняются через `evolve(**changes)`, который собирает новые
данные и заново валидирует модель. Вложенные коллекции — кортежи; словари
копируются при изменении.

## Последствия

- Снимок можно безопасно хранить, сравнивать и показывать в UI.
- `snapshot_hash()` стабилен: одинаковые данные дают одинаковый sha256.
- Каждый шаг создаёт новые объекты — есть накладные расходы на валидацию;
  для больших карт это осознанный компромисс (см. T38).
- Нельзя «поправить поле по месту»: любое изменение — явный `evolve`.

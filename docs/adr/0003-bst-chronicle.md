# ADR 0003: BST-летопись

- **Статус:** принято
- **Дата:** 2026-11-23
- **Связанные задачи:** T09, T11

## Контекст

Летопись должна поддерживать выборку событий по году, диапазону и фильтрам
по типу/фракции/тайлу. События добавляются в хронологическом порядке, но
запросы нужны и по произвольным годам. Нужна детерминированная структура
без внешних зависимостей.

## Решение

`Chronicle` хранит события в бинарном дереве поиска `BinarySearchTree`,
где ключ — год, значение — список событий. Дерево поддерживает вставку,
поиск, диапазонный обход, удаление и сериализацию в отсортированный
список. `Chronicle.to_markdown()` и `to_json()` обходят события по годам.

## Последствия

- Выборка по году и диапазону — O(log n) на поиск плюс размер результата.
- Порядок событий детерминирован: год, затем id.
- Дубли годов хранятся как мультимножество в списке.
- Для очень больших историй дерево не оптимально по памяти; при
  необходимости его можно заменить на сбалансированное или внешнее
  хранилище, не меняя API `Chronicle`.

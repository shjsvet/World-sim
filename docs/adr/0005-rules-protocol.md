# ADR 0005: протокол правил

- **Статус:** принято
- **Дата:** 2026-11-23
- **Связанные задачи:** T13, T20–T45

## Контекст

Симуляция состоит из десятков независимых механизмов: экономика, войны,
культура, магия. Нужно добавлять и отключать их, не меняя движок, и
гарантировать предсказуемый порядок применения. Падение одного правила не
должно ломать весь мир.

## Решение

Правило — структурный `Rule` Protocol: `name`, `priority`,
`apply(state, ctx) -> RuleOutcome`. `StepContext` содержит год, конфиг,
`Rng`, кэш метрик и очередь боёв. `RuleOutcome` описывает изменения тайлов
и фракций, события, войны и торговые маршруты. Движок сортирует правила по
`(priority, name)` и применяет результат через `WorldState.evolve`.
Плагины оборачиваются в `PluginRule`: падение отключает правило и пишет
`CUSTOM`.

## Последствия

- Новое правило не требует правок движка — достаточно реализовать три
  атрибута.
- Порядок детерминирован; конфликт приоритетов разрешается именем.
- Правила не должны хранить состояние между шагами — источник истины
  снимок мира.
- Ошибки плагинов изолированы, но молчаливое отключение видно в летописи.

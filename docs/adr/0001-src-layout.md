# ADR 0001: src-layout

- **Статус:** принято
- **Дата:** 2026-11-23
- **Связанные задачи:** T02, T03

## Контекст

Пакет должен импортироваться как `worldsim`, тесты — работать с
установленным пакетом, а не с случайными файлами из корня. Нужно исключить
ситуацию, когда `import worldsim` подхватывает каталог из текущей папки, и
сохранить чистый корень репозитория.

## Решение

Исходники лежат в `src/worldsim/`; `pyproject.toml` использует
`[tool.setuptools.packages.find] where = ["src"]`. Установка —
`pip install -e .`; тесты запускаются из корня и импортируют установленный
пакет.

## Последствия

- Корень остаётся свободным для `docs/`, `tests/`, `scripts/`, `plugins/`.
- Без установки пакет не импортируется — это защищает от скрытых
  зависимостей от рабочего каталога.
- CI обязан выполнять установку перед тестами.
- Публичный API не является целью: приложение запускается через
  `worldsim` / `python -m worldsim`.

# ADR 0004: JSON-репозиторий

- **Статус:** принято
- **Дата:** 2026-11-23
- **Связанные задачи:** T24–T29

## Контекст

Нужна «машина времени»: сохранять снимки мира, возвращаться к прошлым
годам, ветвить альтернативные реальности и сравнивать версии. Внешняя
СУБД или git-сервер усложнили бы установку; снимки должны переноситься
вместе с проектом.

## Решение

Репозиторий `.worldsim/` хранит объекты в JSON:
`objects/<commit_id>.json` (коммит + снимок + летопись),
`refs/branches/<name>` и `refs/tags/<name>` — указатели на id, `HEAD` —
текущая ветка или коммит. `commit_id` — sha256 от родителя, года,
сообщения и `snapshot_hash`. Запись атомарная (временный файл +
`os.replace`). Дополнительно есть in-memory `Repository` для быстрых
сценариев и тестов.

## Последствия

- Ветвление и checkout не требуют сервера и работают офлайн.
- История воспроизводима: id детерминирован, снимок валидируется при
  чтении; повреждённый JSON даёт `RepositoryError`.
- Нет слияния веток: альтернативные реальности развиваются независимо.
- Одинаковые снимки идемпотентны, но старые объекты остаются на диске;
  чистка истории — отдельная задача.
